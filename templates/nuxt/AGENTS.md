# Agent instructions

This project uses Cursor skills and rules for **where files go** and **how to write Nuxt / Vue UI**. Recipe libraries are examples only.

## Always follow

- **Structure:** [.agents/skills/project-structure/SKILL.md](.agents/skills/project-structure/SKILL.md) — `app/` layouts/pages, naming, placement
- **Nuxt:** [.agents/skills/nuxt/SKILL.md](.agents/skills/nuxt/SKILL.md) — Nuxt conventions, auto-imports, server routes
- **Rules:** [.agents/rules/](.agents/rules/)

Everything Vue lives under `app/` (`~/` / `@/`). Locales under `i18n/`. Nitro under `server/`. No top-level `src/`.
