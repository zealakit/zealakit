# Alembic

- `alembic.ini` + `migrations/` (`env.py` reads `DATABASE_URL` and the SQLAlchemy `Base`).
- `migrations/versions/0001_create_items.py` creates the sample table.

## Commands

```bash
uv run alembic upgrade head                          # apply
uv run alembic revision --autogenerate -m "describe" # new migration from model changes
uv run alembic downgrade -1
```

## Conventions

- Never edit an applied migration; add a new one. Review autogenerated migrations before committing.
- Run migrations in deploy/CI, not at application start. `AUTO_CREATE_TABLES` in `infrastructure/persistence/database.py` is `False` so the app never creates tables behind Alembic's back.
